# GP_UEAssignment
 
A PCG map creator which allows the user to generate simple maps for dungeon/cave usage, using Cellular Automata and Marching Sqaure techniques. The user is able to generate and manouver around the map created, with a simple "collecy the pickups" style game being included in the playing stage of the tool. 

I chose PCG as my mechanic of choice for this module as I love The Binding of Isaac games, and I've done a lot of PCG projects in the past and wanted to learn some more advanced techniques (such as Marching Sqaures)
